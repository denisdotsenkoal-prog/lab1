## Використані приклади з лекції
Серверний код обох реалізацій адаптовано на основі прикладів першої лекції з каталогу **`02-catalog`**:

- **Node.js (`node/server.mjs`):** адаптовано з прикладу `02-catalog/node/server.js` (використано створення HTTP-сервера через `http.createServer`, отримання шляху запиту, формування статусів та заголовків відповіді `res.writeHead`). Для роботи ES-модулів (`import`) без `package.json` файл збережено з розширенням `.mjs`. Файли читаються синхронно через `fs.readFileSync`.
- **Python (`python/server.py`):** адаптовано з прикладу `02-catalog/python/server.py` (використано клас `BaseHTTPRequestHandler` та метод `HTTPServer`). Для роботи з файловою системою використано `Path` із модуля `pathlib`, а маршрутизація реалізована через виділення чистого шляху за допомогою `urllib.parse.urlparse`.

## Інструкція з запуску та адреси застосунків

Для відтворення запуску переконайтеся, що встановлено Node.js та Python 3. Кожен сервер працює у своєму терміналі на власному порту.

### 1. Запуск реалізації на Node.js (Порт 3001)

1. Відкрийте термінал і перейдіть у каталог `node`:
bash
cd node

2. Запустіть сервер:
bash
node server.mjs

3. **Адреса застосунку:** http://localhost:3001

---

### 2. Запуск реалізації на Python (Порт 3002)

1. Відкрийте окремий термінал і перейдіть у каталог `python`:
bash
cd python

2. Запустіть сервер:
bash
python server.py

3. **Адреса застосунку:** http://localhost:3002


## Перевірка за допомогою `curl`

Виконайте команди в окремому терміналі для перевірки відповідності контракту:

bash
curl -i http://localhost:3001/
curl -i http://localhost:3001/about
curl -i http://localhost:3001/styles.css
curl -i http://localhost:3001/nope
curl -i http://localhost:3001/missing/page
curl -i 'http://localhost:3001/about?source=test'
curl -i http://localhost:3001/about.html

*(Так само і для Python-сервера, але підставте порт `3002` замість `3001`)*.
