Реалізація

Застосунок демонструє обробку HTTP GET-запитів, явне зіставлення маршрутів із файлами public, встановлення статусів і Content-Type та повернення сторінки 404 без перенаправлення.

Реалізовано двома стеками: Node.js та Python. HTML і CSS читаються з файлів.
